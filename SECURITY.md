# Security policy

This repository is a public portfolio website.

## Reporting a vulnerability

If you discover a security issue, please avoid publishing exploit details or testing against infrastructure without authorization. Contact the maintainer through the contact details on the portfolio or GitHub profile.

Include a clear description, affected component, reproduction steps that do not cause damage, and potential impact. Do not include secrets or personal data in a public issue.

## Scope

Issues affecting this repository's code or its deployment configuration are relevant. Third-party systems and linked websites are not automatically in scope for security testing.

# Contributing

Thanks for your interest in this portfolio.

## Content guidelines

- Contributions should be accurate, reproducible, and relevant to cybersecurity education.
- Lab write-ups must come from authorized environments and comply with the platform's publication rules.
- Never include real credentials, access tokens, personal information, or proprietary data.
- Distinguish confirmed findings from hypotheses and experiments.
- Keep the site accessible and usable on mobile devices.

## Development workflow

1. Create a focused branch.
2. Make one coherent change.
3. Run `npm install` and `npm run build`.
4. Open a pull request explaining the change and any testing performed.

Do not submit fabricated certifications, experience, exploit results, or activity metrics.
